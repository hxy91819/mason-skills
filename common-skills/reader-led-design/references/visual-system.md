# 视觉系统规则

[reader-led-design](../SKILL.md) 第 3 阶段的参考。token、型别角色与元件以专案文件指定的共用 token、主题来源与元件为准；本档只讲构图、层次与何时该用哪种原语。

## 网格与对齐

- 标题栏、页标题、章节、证据与页尾共用同一套外层网格。阅读用散文占约一半到六成宽；表格、图表、计算器、图解与主要比较可占全宽。
- 每个物件对齐到共享的边、基线、网格线或刻意的视觉中心。同侪区块共用型别角色、数值位置、内部列与动作对齐。分栏的标题与段落在第一行文字基线对齐。
- 栏间距要一眼可辨。换行的标题、标签与散文不得看起来跨到隔壁栏；会被误读成同一句时，加宽间距、缩短内容或改为堆叠。
- 留白要放大焦点。分栏填不满、第三项落单、证据延后造成的大块空白是版面失败，重排或重新平衡。三个真正的同侪通常占一列三栏；刻意突出的一个可以更宽，但差异必须有意义。
- 份量不等的发现不塞进等大的格子。排序、分组，或给决定性的发现更大视觉份量，让几何符合论点。
- 跨容器比较左缘：标题、页签、筛选、表格首列与分页各自对齐所属表面的内容线。分开量外框与文字起点，确认表面内距一致且只套用一次；多栏网格、展开列与独立子表面按角色判断，不强求所有 x 相同。
- 增加栏数或缩图数后，以代表性长标签检查预设画面仍能区分对象；共同前缀截断、技术键与裁切不能靠缩字或 tooltip 补救，应重排、保留图说宽度或允许换行。

## 字体与节奏

- 散文、标题、标签、控制项、表格、KPI、日期、数量、百分比、时长、金额用无衬线正文字体。等宽字只用于程式码、指令、路径、原始 token、时间戳与短识别码（区域、方案、SKU、帐号、环境 ID），而且只设识别码本身，不设整句或整表。
- 只用专案定义的型别角色与字重 token，不自创字级与数字字重。展示级字级只给全页唯一的定义性陈述；页标题、章节标题、子标题、导言、正文、标签、图说与中继资料各有角色。强调要稀少。对齐比较用等宽数字。同侪永远共用角色、字级、字重、行高与数字处理；不因字串较长或数值较大而改尺寸。
- 垂直节奏来自关系，不是一个通用堆叠值：
  - 标题 → 第一段：近。
  - 段落 → 段落或清单：一个正文节奏。
  - 标签 → 数值 → 细节：同侪之间完全一致。
  - 内容群 → 新章节：明显更大。
  - 图说或来源 → 它限定的证据：近到能一起读。
- 每个间距只有一个拥有者。由 flow、stack、grid 或页面自订的包装设定间距，子元素不再加预设 margin。群内间距小，群间间距中，章节转折大；最大的间距保留给两个实质章节之间的真正断章，不当预设堆叠值。
- 判断整个转折，不只看 token。大间距挨著填不满的分栏、短章节或稀疏的最后一列会放大空洞，即使 token 合法；缩小间距、重新平衡或改为堆叠。
- 标题、说明与清单不当成自订格子里互不相关的兄弟节点。把内容分组、对齐同侪的对等角色，让群组拥有内部节奏。不用一次性 margin 修补单一尴尬转折，修分组或间距拥有者。
- 正文保持舒适的字级与行高，不用小灰字挤密度。每行约 60 到 68 个拉丁字元，中文对应约 30 到 40 字。先改写，再缩小。
- 层次先靠字体建立，再靠表面或色彩。段落用间距分隔，不用首行缩排。检查重要断行；大标题或导言的孤字靠改文案或量尺处理，不缩小单一元素。
- 标题用句子写出客户具体的主张或读者问题。避免全大写眉标、装饰性章节编号、人工对称、重复句式、泛泛称赞与内部作者用语。用具体名词与主动动词。好的标题说发生了什么、改变了什么或要做什么决定，不说文件类型。
- 本 skill 的作者用语（构图、层次、焦点关系、中介）不得漏进页面文案。

## 色彩、表面与边界

- 以单色设计。色彩只在对状态、动作或资料有显著意义时使用，并配一个非色彩线索。建议、节省金额、成本项或较长的长条不因「有利」或「重要」就涂绿。图表色只用于区分序列或编码有来源的状态。明暗主题隐式支援，不加可见切换器。
- 页面通常是一张连续画布。只有在表达选取、互动、警告、对比，或间距无法表达的真正分组时才加表面或边界。先用间距、对齐、字体与密度变化，再考虑框线或盒子。
- 不把每个章节、指标或比较都包进卡片。避免巢状面板。圆角克制且与专案一致。
- 分开诊断「数量」与「强度」。页面显得忙，就移除、合并或重排内容；显得吵，就减少互相竞争的色彩、尺寸、字重、框线、表面与动效。保留一个刻意的锚点，克制不等于把页面压平成中性的一片。
- 硬性拒绝装饰性渐层、渐层文字、光晕、斑块、条纹、纹理、网格背景、玻璃效果、纸张模拟、彩色侧栏、装饰阴影与假景深。渐层只有在是带标签的连续资料尺度时才可接受。

## 资料与证据

- 视觉编码要诚实。单位、期间、母体、基准与关键比较对象放在它们限定的证据旁。长度编码用零基线，除非明确标示的区间或差值视图更能回答问题。不用裁切的长条夸大小差异，也不用几乎等长的总量长条掩盖差异；在同一基准上显示精确差值。长条轨道不当分隔线或装饰。同侪长条共用一个标明的尺度，长度必须编码数值，否则改用对齐的文字。
- 分母不同时，从读者问题明确选「数量」或「比率」，不把原始分子当同基准比较。长度编码比率就显示数量与基数；编码数量就说明为何量而非率回答问题。两者都不足时用对齐文字或分开的视图。
- 重复的水平长条当成一个版面排，不逐列排。整组一条共享标签道、一条绘图道、每个对齐数值或注解一条共享道。每条轨道起迄都在同一网格线上，只有填充长度变化。任一列的标签、数值或注解改变绘图宽度就是版面失败；用父层 grid、subgrid 或固定共享轨道，不用各列独立解析的内容尺寸栏。
- 直接标签优于图例。每个图表标签留一条清晰的道，标记、线、括号或注解不穿过字形框。图表文字在两种主题下都可读。用图说说明读者该注意什么、图表不能证明什么。关键图表资料提供语意表格或简洁文字替代。
- 图表是主要证明时，给它足够宽度、高度与对比承载第一眼。视觉显著度与论点一致：决定性的序列、例外或门槛在两种主题下都最强调，支援证据退后但仍可读。

### 表格是证据，不是装饰

- 用语意 `<table>`，有 caption、head、body，可选 foot。
- 预设占全宽。章节引言放表格上方，不把帐册卡在标题、注记或空栏旁边填分栏。
- 每栏表头对齐方式与该栏所有储存格一致：文字栏与表头靠左，数值栏与表头靠右，含占位符与合计。表头绝不置中或靠左放在靠右数值上方。
- 同侪单位与精度一致，不加假精度。
- 只有多行表头底部对齐；表身储存格以第一行文字基线对齐，包含有储存格换行时；不垂直置中或底部对齐表身列。
- 列标签栏给一般短标签一行放得下的宽度。隔壁栏还有闲置宽度时，短列标签不换行。真要多行就在词边界换行并保留共享的第一基线。
- 不花一栏重复同一类别。类别改变列的解读方式时，用语意列群组或拆表；只有读者要靠该值做列级排序或筛选时才留类别栏。
- 一般短表用正常密度，紧凑密度留给真正密集的查询表。
- 只有来源支持建议时才突显建议列。
- 先绕读者的查询任务重排栏位，再缩小或换行。
- 密集证据先给足宽度，再考虑分栏。五栏以上，或表头在一般桌面宽度下会换行的表，通常独占章节全宽。绝不裁切、截断或缩小表头来保留旁边的散文栏；把引言移到上方或简化栏位。
- 简洁差异用定性比较；需要逐列精确扫读时用比较表。同侪栏共用型别角色与列起点；某一方需要不同结构，就不是同侪网格。

## 计算器与互动

- 互动是证据，不是装饰。计算器让一个模型可读，并让读者测试会实质改变结果的假设。
- 定义一个标准状态模型：变数、固定输入、公式、单位、完整精度、范围、步进、预设、显示精度与依赖。每个变数由一个控制项拥有；固定参数不是控制项。预先渲染预设结果。从完整精度状态原子性地更新所有相依输出，再格式化显示。
- 焦点结果、控制项与支援输出在同一个工具里。操作计算器是读者主要任务时，可用的工具是第一屏的主物件，不延到超大引言或稀疏的 hero 下方。前面不放同一答案的仪式性静态版，后面不放预设情境的回顾。只有在帮助读者信任或使用模型时才解释公式、假设、边界或解读。
- 用原生控制项、可见标签、必要时才加辅助文字、清楚的单位、可见焦点与一条简洁的即时状态。保留无效输入与上一次有效结果，不默默夹限或重设。键盘与萤幕阅读器都能操作所有控制项与结果。

## 动效

预设静止。只有在解释状态变化、保持连续性或确认动作时才加动效。基础体验不靠动效就完整，并尊重减少动效偏好。不做自动卷动跑马灯、模拟打字游标、装饰性脉动指示、滚动逐段揭露、悬停移动影像、弹跳、视差、电影式转场、声音或场面。

正式页面的「惊喜」来自异常清晰的证据或异常低的互动摩擦：一眼看懂的比较、让模型显而易见的计算器、替客户省掉工作的客制互动。不用笑话、庆祝、彩蛋或特效制造个性。

## 媒体与图示

只在是证据或实质增进理解时使用提供的截图、图解、客户媒体或 logo。不加素材图库影像、装饰性 AI 插图、抽象形状、假产品截图或强制 hero 媒体。图示不当装饰，不放进彩色方块。优先文字标签，除非既定图示让动作辨识明显更快。

## 无障碍与响应式

- 用 landmark、唯一且描述性的 `h1`、有序标题、跳至内容连结、原生控制项、语意表格、figure 与 caption、可存取名称、可见焦点与文字替代。达到 WCAG AA，不单靠色彩传达。来源顺序即阅读顺序。
- 不隐藏页面溢位。grid 与 flex 子元素给 `min-width: 0`；先重排再缩小。保留可读的字级与控制项尺寸。短比较可以堆叠；长帐册在重排与简化都无法保留查询时才局部卷动。页面在明暗主题与桌面、窄萤幕下都可用，且没有可见的主题切换器。
