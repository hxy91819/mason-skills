# 工作簿模板

默认路径 `docs/steward/<topic>.md`。三段固定，没有内容的段写"无"。准入判据见 SKILL.md「工作簿」。

```markdown
# <目标一句话>

更新：<YYYY-MM-DD>

## 路线

- [x] <阶段 1：一句话说明产出>
- [ ] <阶段 2> ← 进行中（最近线程 thr_xxx）
- [ ] <阶段 3>

## 关键决策

- <YYYY-MM-DD> <决定一句话>。原因：<一句>。影响：<哪些阶段或模块>。

## 用户待办

| 状态 | 事项 | 为什么只能用户做 | 挡住 | 提出 |
| --- | --- | --- | --- | --- |
| 待办 | <做什么> | <凭据/外部账号/线下确认> | <阶段 N> | <YYYY-MM-DD> |
| 已完成 | <做什么> | ... | ... | <YYYY-MM-DD> |
```

项目 `AGENTS.md` 加一行，使任何会话都能接上：

```markdown
管家工作簿在 `docs/steward/<topic>.md`，存在时先读，只报未完成的用户待办。
```
