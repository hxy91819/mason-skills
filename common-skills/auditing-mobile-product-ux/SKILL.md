# 移动端产品体验审计

访问用户指定环境的移动端版本。客户可能反馈移动端体验很差，而开发时主要关注桌面端，忽略了这部分体验。

以专业产品经理的角度，使用真实浏览器进行探索和视觉识别，定位一批移动端体验问题。

使用当前主流手机尺寸进行检查：

- iPhone 16：`393 × 852` CSS px
- iPhone 17：`402 × 874` CSS px

每个体验问题说明：

- 问题是什么，以及为什么会影响体验
- 改进建议
- 实际真实截图
- 进入路径
- 使用的账号，不记录密码

输出一份 HTML 报告，并在报告中配上本次探索实际截取的图片。用户没有指定保存位置时，暂时存放在本地。
