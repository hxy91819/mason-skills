# Review HTML Report

统一审查结果的展示：问题卡、红框证据、文字建议对照、真实修复前后滑块及反馈复制。审查结论和执行权限由上游负责，本技能只消费已有记录、生成报告并验证展示。按名称由宿主加载本技能；脚本从本技能解析后的根目录运行，不依赖调用方的安装位置。

## 输入与生成

读取 [references/report-data.md](references/report-data.md)，把已有 findings、状态和证据映射为 JSON。已有 PPT JSON 可直接使用；spec-leak 的真实修改映射为改前/改后文字及图片对照，未执行项保留建议。两个上游默认交付 HTML；用户明确只要文字时由上游跳过渲染。

```bash
python3 <本技能根目录>/scripts/build-report.py --data <记录.json> --check
python3 <本技能根目录>/scripts/build-report.py --data <记录.json> --out <报告.html>
```

路径参数使用绝对路径；含空格时加引号。报告写到用户指定产物目录或临时目录，返回可点击链接。默认不发布到外部站点。

## 展示契约

- 统一用折叠问题卡，支持全部展开/收起。每张卡包含问题、核心变化、建议/实际改动和处理状态；视觉与内容分组，组内按严重度排列。
- 文字对照展示原文与实际改后文案；未执行项展示「建议 · 尚未执行」。实际改后全文与完整建议稿分别折叠展示。
- 已修项可展示真实前后滑块，默认中点，支持拖动、键盘及并排切换。同页/同对象、同视口尺寸的图片由审查者确认；未修项不生成修复对照。两图相同时省略无变化滑块。
- PPT 默认只内嵌已修项必要图片。spec-leak 通过 `annotatedImg` 显式提供审查的标注证据；纯文本审查不要求截图。全量截图与过程记录留在本地，不平铺进报告。
- 背景、紧凑覆盖表和建议稿按输入提供；影响结论的缺口始终展示。反馈支持待定/采纳/讨论/驳回、单项及全部复制。反馈不会修改源文件或审查结果；页面刷新后不保留交互选择，需要保存时复制反馈。

## 验证与完成

`--check` 校验字段、图片并输出覆盖/分组状态；它只检查记录一致性，不证明审查者真的看过图。纯文本报告不会要求视觉交互或图片证据。

生成后在浏览器检查折叠、文字换行、证据可读性和反馈复制；有滑块时检查极值、中点、并排往返及 resize。无剪贴板权限时使用页面的可复制文本框。已有报告需要更新时先完成数据/图片校验，失败保留原 HTML。交付 HTML 链接、输入记录位置和剩余展示缺口；不据渲染成功改写上游审查结论。
