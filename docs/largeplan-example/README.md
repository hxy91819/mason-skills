# 内部文档站一次性令牌登录

本目录是一次性令牌登录项目的完整门户示例，演示 large-task-planning 技能的用法：人读 Markdown 保存意图，脚本维护的 Agent JSON 保存动态状态。

## 项目一览

内部文档站目前用共享密码登录。密码长期不变，也无法区分使用者。本项目改为：员工在登录页提交企业邮箱，收取一次性令牌邮件，点击链接或输入验证码即可登录。站点同时获得防滥用能力和完整的登录审计。工程状态与下一步请看[项目进展](项目进展.md)。

## Agent 入口

Agent 从[项目进展](项目进展.md)的可领取项选择工作，用 `status --json` 取执行卡路径，只加载该 Story 及其直接引用的资料。动态状态唯一源在 [agent/](agent/) 目录：五张执行卡、[风险与阻塞](agent/风险与阻塞.json)、[项目门禁](agent/门禁.json)和[一次性令牌契约](agent/令牌契约.json)。
