# 令牌验证与会话建立

## 愿景

员工点击邮件里的链接，或在登录页输入验证码后，文档站完成校验并让员工进入站点。浏览器在会话有效期内保持登录，页面能看出当前登录的是哪位员工。

## 范围

校验令牌摘要、有效期与单次标记，成功后复用文档站现有会话机制登录；失败时给出可重新申请的提示。包含链接落地页处理与验证码输入框。申请频控、临时锁定、定时清理和审计事件不在本 Story 内。

## 关键决策

1. **复用文档站现有会话机制与员工邮箱身份，不新建账号体系。**
   - 决定者：用户。
   - Agent 建议：评估新建用户表和接入公司单点登录后，建议直接复用现状，用户采纳。
   - 结果与影响：用户不需要迁移账号，也不用运维新的身份服务；代价是身份能力受现有会话机制限制，单点登录留待未来项目。

## 验收标准

- 有效令牌首次使用登录成功，会话在有效期内保持。
- 过期令牌、错误验证码和被篡改的链接都登录失败，并提示重新申请。
- 登录成功后页面显示当前员工邮箱，退出登录功能可用。
- 共享密码入口在本 Story 保持可用，下线动作属于 STORY-05。
