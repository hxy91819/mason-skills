# 一次工程成果汇报的 PPT 制作复盘

这份文档记录一次工程实践演示稿反复修改后的经验，供类似需求参考。它是一份复盘，不是制作技能，也不规定所有 PPT 都采用同一种结构。文中只保留通用经验；项目原件、业务数字、会议转写和审查截图留在各自项目里。

## 先想清楚听众要判断什么

这次采用的是比较典型的成果答辩叙事：先让听众知道做成了什么，再解释关键难点和解决办法，最后用结果证明，并归纳到组织价值。

这个顺序对答辩、晋升和阶段成果汇报有效，因为评委需要快速判断贡献、难度和成效。开头给出成果后，后续实践就有了理解的背景。难点只挑能解释方案价值和关键取舍的部分，避免把困难本身写成成绩。

换一个场景，展开方式也应变化：技术分享更需要讲清机制与取舍，方案评审更需要比较选项和说明决策依据，培训则围绕听众能否学会并操作。先看这次要促成什么理解或决定，再选叙事。

## 具体实践要讲到动作和产物

前期稿件列出了不少数字，但仍然回答不了“你们到底怎么做的”。补回具体实践后，内容才变得容易理解。

一页实践可以检查三个问题：处理的对象是什么，关键动作是什么，留下了什么可观察的产物。例如，讲验证环境时，把代码版本、环境和验证结果如何对应画出来；讲失败回修时，说明谁收到哪些证据、据此做什么、如何再次验证。机制图里的箭头应表达真实关系。

数据紧跟要证明的动作，并保留项目、样本、时间和阶段口径。阶段测试不等于自然用户收益，若干项目的数据也不能拼成一条已经验证的完整收益链。

这次每章将实践展开为数页、把数据集中展示，适合材料和演讲目的。具体页数是本次取舍，不应成为后续稿件的固定配额。

## 转场本身也是内容

身份、经历和成绩之间有时缺少因果上的连接。比如，上游维护经历如何关联到内部项目，需要说明从中吸收了哪些经验、如何结合自身积累应用到项目执行中。只把两件事放在相邻页面，听众未必会自行建立联系。

大纲阶段就可以写出关键转场句：为什么从开篇进入第一章，前一章解决后还剩什么问题，最后为什么能谈组织价值。章节过渡页提供停顿和方向，但不能代替这层解释。

结尾可以归纳为工程能力可复用、任务与角色能够接续、经验和反馈能够回流。没有组织整体效率的测量时，把它讲成机制与价值判断，保留事实边界。

## 先分清材料里的事实和解释

会议里某人的提议、大家最终的决定、制作者的推断，是不同性质的信息。整理转写时应保留这种区别；清理术语、说话人标签或页段目录，也要能追溯回原材料。

只有聚合数字时就按聚合口径呈现。缺少具体对象的名称、链接或运行记录，不能用邻近案例补成同一个对象。旧版 PPT 可以提供表达和实践素材，涉及事实时仍回到原始依据核对。

来源信息适合放在讲稿或来源页里，主画面保留影响理解的范围说明。重要限制也应在口播中说明，避免主屏结论超出证据。

## 视觉通过需要真实看图

这次最明确的漏检，是连续内容页的主体偏小、偏上，底部留有大块空带。自动测量已经给出线索，审查却把它们笼统解释成“有意留白”。问题出在画面判断和裁决理由不充分。

判断留白时，看它服务哪段内容、是否维持主次和分组，再与同类页面比较。封面和章节页需要停顿，内容页则要看关键图文是否足够清楚。没有适用于所有页面的底部空白像素合格线。

修复要同时看卡片和卡片里的有效内容。只增加背景高度，可能把外部空白搬进卡内。放大字号和调整宽度后，还要查看实际折行：原先正常的句子可能出现孤字，优先通过宽度、行距和语义成组解决，保留已确认的文字。

脚本负责提供可核查线索，审查者负责解释画面。跨换行拼接文本可能制造中英空格误报；引号偏窄也不能单凭宽度证明字体错误。截图已生成、工具已打开、视觉判断成立，分别是三件事。主 Agent 要复看用户指出的页和重要争议项，对最终结论负责。

具体执行沿用 [ppt-visual-review](../common-skills/ppt-visual-review/SKILL.md)，这里保留经验和原因，不复制它的运行清单。

## 把迭代和交付做得容易接手

先做少量有代表性的页面，尽早看到问题页、实践图和数据页的真实效果，再展开整稿。已经认可的内容及时固定，修改前留可恢复的基线，让并行工作围绕同一份输入进行。局部修改先做针对性检查；进入既定全篇视觉复审时，仍按其覆盖范围执行。

源码、讲稿、来源和成品一起交付，并保留构建入口。特别检查忽略规则有没有漏掉核心图片、内嵌完整讲稿是否跟随新页序、通用验证截图是否属于当前版本。单文件能打开，只证明成品可用；源码依赖齐全才便于后续继续修改。

最终记录围绕一个明确的成品版本组织。哈希用来确认审查对象没有变化，不作为质量结论；字体子集构建可能产生不同字节，复建验证要明确结构、字形和功能的等价标准。

过程材料保留到能复现问题和解释决定即可。优先维护一份当前状态和有代表性的前后对照，大包快照、重复构建和临时调试产物按需要留在本地，避免每轮都增加一套难以维护的档案。

下次制作时，先回到三个问题：听众要判断什么，哪些具体实践最能说明贡献，哪些证据足以支持结论。其余结构和版式围绕这次的答案调整。
